Project Name: Εκπαιδευτική Συνεργατική Εφαρμογή Πίνακα Σημειώσεων

Είδος: Διπλωματική Εργασία

📝 Περιγραφή
Μια συνεργατική εκπαιδευτική εφαρμογή που επιτρέπει στους χρήστες να δημιουργούν σημειώσεις και να ανεβάζουν πολύμεσα, με δυνατότητα διαμοιρασμού σε πραγματικό χρόνο.

🛠 Τεχνολογίες Ανάπτυξης (Tech Stack)
Frontend:

HTML5 & CSS3: Δομή και αισθητική.

Bootstrap 5: Framework για πλήρως Responsive Design (κινητά, tablets, desktop).

JavaScript & jQuery 3.6: Δυναμική διαχείριση της διεπαφής και των συμβάντων (DOM manipulation).

Backend:



Composer: Διαχείριση εξωτερικών βιβλιοθηκών (PHPMailer για ανάκτηση κωδικών).

Data & Security:

MySQL: Βάση δεδομένων (μέσω XAMPP).
ackend: PHP 8.x (Αντικειμενοστραφής προγραμματισμός).

Database: MySQL.

Frontend: HTML5, CSS3, jQuery (JavaScript Library).

Data Exchange: JSON (χρήση για την ανταλλαγή δεδομένων μεταξύ PHP και JavaScript).

Dynamic Features: AJAX (για ανανέωση περιεχομένου, όπως το Live Search, χωρίς reload της σελίδας).

Dependencies: Composer (PHPMailer για την ασφαλή αποστολή email ανάκτησης κωδικού).
AJAX & JSON: Ασύγχρονη ανταλλαγή δεδομένων μεταξύ Client και Server (π.χ. Live Search, αποθήκευση χωρίς reload).

Security: Σύστημα ρόλων χρηστών, επαλήθευση email και κρυπτογράφηση κωδικών πρόσβασης.

🚀 Οδηγίες Εγκατάστασης (Installation)
Αντιγραφή: Τοποθετήστε τον φάκελο του project στη διαδρομή: C:\xampp\htdocs\noteapp.

Βιβλιοθήκες: Ανοίξτε το τερματικό (Command Prompt) μέσα στον φάκελο και εκτελέστε:
composer install

Βάση Δεδομένων: * Δημιουργήστε μια βάση στη MySQL με όνομα noteapp.

Κάντε εισαγωγή (Import) το παρεχόμενο αρχείο .sql.

Εκτέλεση: Ανοίξτε τον browser και πληκτρολογήστε: http://localhost/noteapp.
