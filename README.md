Σχεδίαση και Υλοποίηση Διαδικτυακού Πληροφοριακού Συστήματος Εκπαιδευτικής Συνεργασίας Τύπου Πίνακα Σημειώσεων

Τίτλος: Η Σχεδίαση και Υλοποίηση ενός Εκπαιδευτικού Συνεργατικού Πληροφοριακού Συστήματος σε Μορφή Ψηφιακού Πίνακα

Περιγραφή
Η εφαρμογή αποτελεί έναν συνεργατικό ψηφιακό πίνακα που επιτρέπει σε καθηγητές και μαθητές να αλληλοεπιδρούν σε πραγματικό χρόνο. Προσφέρει δυνατότητες για διαδραστική μάθηση, σχολιασμό, σχεδίαση, διαμοιρασμό αρχείων και σημειώσεις. Οι χρήστες μπορούν να επεξεργάζονται, να δημιουργούν και να αποθηκεύουν το περιεχόμενο του πίνακα (σημειώσεις, πολυμέσα) μέσα σε αυτό.

Τεχνολογίες Ανάπτυξης (Tech Stack)

Frontend
HTML5 & CSS3: Δομή και αισθητική.

Bootstrap 5: Framework για πλήρως Responsive Design.

JavaScript & jQuery 3.6: Δυναμική διαχείριση της διεπαφής και των συμβάντων (DOM manipulation).

AJAX & JSON: Ασύγχρονη ανταλλαγή δεδομένων μεταξύ Client και Server (π.χ. Live Search, αποθήκευση χωρίς reload).

Backend

PHP 8.x:   διαχείριση της λογικής.

MySQL: Βάση δεδομένων (μέσω περιβάλλοντος XAMPP).

Composer: Διαχείριση εξωτερικών βιβλιοθηκών.

Security & Libraries
PHPMailer: Για την ασφαλή αποστολή email ανάκτησης κωδικού μέσω SMTP Server.

PHP Dotenv: Για την ασφαλή διαχείριση ευαίσθητων δεδομένων (κωδικοί SMTP/DB) μέσω μεταβλητών περιβάλλοντος.

Encryption: Κρυπτογράφηση κωδικών πρόσβασης και σύστημα ρόλων χρηστών,επαλήθευση χρήστων.



Οδηγιες  εγκαταστασης  εφαρμογης

1. Αντιγραφή Project
Τοποθετήστε τον φάκελο του project στη διαδρομή: C:\xampp\htdocs\noteapp.

2. Ρύθμιση PHP (XAMPP)
Ανοίξτε το αρχείο php.ini από το XAMPP (Apache > Config) και ενεργοποιήστε/βεβαιωθείτε για τα εξής:

 extension=zip (Αφαιρέστε το ερωτηματικό ; μπροστά).


Restart τον Apache μετά τις αλλαγές.

3. Εγκατάσταση Βιβλιοθηκών
4. 
Ανοίξτε το τερματικό (Command Prompt) μέσα στον φάκελο του project και εκτελέστε τις παρακάτω εντολές:

composer install //egkatastasi tou vendor phpmailer
composer install  vlucas/phpdotenv

4. Ρύθμιση Μεταβλητών Περιβάλλοντος (.env)
   
Δημιουργήστε ένα αρχείο με όνομα .env στον κεντρικό φάκελο του project και εισάγετε τις ρυθμίσεις σας:

Απόσπασμα κώδικα
DB_HOST=localhost
DB_NAME=noteapp
DB_USER=root
DB_PASS=

MAIL_HOST=smtp.gmail.com
MAIL_USERNAME=το_email_σας@gmail.com
MAIL_PASSWORD="ο_16ψήφιος_κωδικός_εφαρμογής"
MAIL_PORT=587
Προσοχή: Ο κωδικός Gmail App Password πρέπει να περικλείεται σε εισαγωγικά ("").

5. Βάση Δεδομένων
   
Δημιουργήστε μια νέα βάση δεδομένων στη MySQL με όνομα noteapp.

Κάντε εισαγωγή (Import) το παρεχόμενο αρχείο .sql.

6. Σύνδεση με Google (Gmail SMTP)
   
Ενεργοποιήστε το 2-Step Verification στον Google λογαριασμό σας.

Δημιουργήστε ένα App Password (Security > App Passwords).

Αντιγράψτε τον κωδικό στο αρχείο .env.



7. Εκτέλεση
Ανοίξτε τον browser και πληκτρολογήστε: http://localhost/noteapp.


Αντιγράψτε τον 16ψήφιο κωδικό στο πεδίο MAIL_PASSWORD του αρχείου σας .env.
