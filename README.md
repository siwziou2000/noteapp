Εκπαιδευτική Συνεργατική Εφαρμογή Πίνακα Σημειώσεων
Είδος: Διπλωματική Εργασία

Τίτλος: Η Σχεδίαση και Υλοποίηση ενός Εκπαιδευτικού Συνεργατικού Πληροφοριακού Συστήματος σε Μορφή Ψηφιακού Πίνακα

📝 Περιγραφή
Η εφαρμογή αποτελεί έναν συνεργατικό ψηφιακό πίνακα που επιτρέπει σε καθηγητές και μαθητές να αλληλοεπιδρούν σε πραγματικό χρόνο. Προσφέρει δυνατότητες για διαδραστική μάθηση, σχολιασμό, σχεδίαση, διαμοιρασμό αρχείων και σημειώσεων. Οι χρήστες μπορούν να επεξεργάζονται, να δημιουργούν και να αποθηκεύουν περιεχόμενο (σημειώσεις, πολυμέσα) μέσα στο σύστημα.

🛠 Τεχνολογίες

Backend: PHP 8.x 


Database: MySQL (μέσω XAMPP) 


Dependency Management: Composer (PHPMailer & PHP Dotenv) 


Frontend: HTML5, CSS3, Bootstrap 5 (Responsive Design) Javascript


JavaScript: jQuery, AJAX / JSON για Live Search και δυναμική ανταλλαγή δεδομένων 


Security: Σύστημα ρόλων χρηστών, επαλήθευση email και κρυπτογράφηση κωδικών (password_hash) 

🚀 Οδηγίες Εγκατάστασης
1. Αντιγραφή Project
Τοποθετήστε τον φάκελο του project στη διαδρομή: C:\xampp\htdocs\noteapp. 

2. Ρύθμιση PHP (php.ini)
Ανοίξτε το XAMPP Control Panel.

Στο κουμπί Config του Apache, επιλέξτε το php.ini.

Αναζητήστε τη γραμμή ;extension=zip και αφαιρέστε το ερωτηματικό (;). 

Αναζητήστε τη γραμμή variables_order και βεβαιωθείτε ότι περιλαμβάνει το γράμμα "E" (π.χ. variables_order = "EGPCS"). Αυτό είναι απαραίτητο για να διαβάζει η PHP το αρχείο .env.

Αποθηκεύστε το αρχείο και κάντε Restart στον Apache.

3. Εγκατάσταση Βιβλιοθηκών
Ανοίξτε το τερματικό μέσα στον φάκελο noteapp και εκτελέστε:

Bash
composer install


4. Ρύθμιση Μεταβλητών Περιβάλλοντος (.env)
Για λόγους ασφαλείας, οι ευαίσθητες ρυθμίσεις αποθηκεύονται στο αρχείο .env. 

Δημιουργήστε ένα αρχείο με όνομα .env στον κεντρικό φάκελο του project. 

Αντιγράψτε τα παρακάτω και συμπληρώστε τα δικά σας στοιχεία:

Απόσπασμα κώδικα
DB_HOST=localhost
DB_NAME=noteapp
DB_USER=root
DB_PASS=

MAIL_HOST=smtp.gmail.com
MAIL_USERNAME=your_email@gmail.com
MAIL_PASSWORD="your_app_password"
MAIL_PORT=587
Προσοχή: Ο κωδικός Google App Password πρέπει να μπει υποχρεωτικά σε εισαγωγικά ("") λόγω των κενών διαστημάτων.

5. Βάση Δεδομένων
Δημιουργήστε μια βάση στη MySQL με όνομα noteapp. 

Κάντε εισαγωγή (Import) το παρεχόμενο αρχείο .sql. 

6. Ρύθμιση Gmail (για PHPMailer)
Για την αποστολή email επαναφοράς κωδικού:

Ενεργοποιήστε το 2-Step Verification στο Google Account σας. 

Δημιουργήστε ένα App Password: Settings -> Security -> App Passwords. 

Επιλέξτε "Mail" και "Generate". 

Αντιγράψτε τον 16ψήφιο κωδικό στο πεδίο MAIL_PASSWORD του αρχείου σας .env. 

💻 Εκτέλεση
Ανοίξτε τον browser και πληκτρολογήστε: http://localhost/noteapp.
